# Frameworks

Every lens this brain can apply. One file per thinker or source, made from `_TEMPLATE.md`. A framework is not usable
until it has boundary conditions and a retrodiction score: `kea check` warns about any that lack them.

Frameworks with `always_apply: true` go into every council packet. The others go in only when a plan names them.

## Rules

- One new framework a month at most. Six half read lenses are worse than one that gets applied.
- Before naming a thinker in a plan, read the relevant section here. Citing a source for the opposite of what it
  argues is worse than citing nothing: it manufactures confidence that was never earned.
- A framework with an empty application log after 90 days gets archived. It is decoration.
